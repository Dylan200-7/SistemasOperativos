# Capítulo 2: Administración Segura de Usuarios y Accesos

## Objetivo

Comprender la importancia de la gestión de usuarios y permisos dentro de un sistema Linux.

## Temas Desarrollados

- Identificación de usuarios.
- Tipos de cuentas.
- Gestión de credenciales.
- Control de acceso.
- Asignación de permisos.

## Análisis

La correcta administración de usuarios permite restringir el acceso a recursos sensibles y facilita la auditoría de actividades realizadas dentro del sistema.

## Conclusión

La asignación adecuada de permisos contribuye a fortalecer la seguridad y minimizar los riesgos de acceso no autorizado.
